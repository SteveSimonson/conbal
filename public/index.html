03 / A short path to live

Shape the moment. Keep the page.

Conbal separates fast-moving content from the slower work of rebuilding a site. Your structure stays steady; your message gets room to move.

Create the moment

Write trusted HTML and scoped CSS, or import reviewable drafts from an LLM-ready CSV.

Publish with control

Preview first, publish when it is right, and unpublish instantly without removing placement.

Place it anywhere

Install one deferred script. Page-aware delivery chooses useful locations and fresh samples.

Many sites, one account

Switch between properties while content and analytics stay site-scoped.

Useful dimensions

Responsive, 300×250, 336×280, 728×90, 160×600, or 320×100.

Bulk generation

Download the Markdown guide and import validated, reviewable CSV drafts.

Delivery analytics

See calls per balloon, selected site, every site, and the whole account.

Raw creative control

Bring your own trusted HTML and scoped CSS without a forced template.

Fast by default

A dependency-free loader fetches only the published content present on the page.
